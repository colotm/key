# Language and Keyboard Layout Data

A clean, sorted repository of regional languages, dialect continuums, and specialized keyboard layout mappings across global regions.

## Project Overview

This dataset consolidates linguistic entries spanning multiple language families, including:
* **Oceanic / Polynesian:** Standard Pasifika input configurations.
* **Yolngu Matha:** Pama-Nyungan language variants from Northern Australia.
* **Niger-Congo & Afroasiatic:** Detailed classification of Nigerian, Nilotic, and Horn of Africa languages.

## Dataset Structure

The list is processed and sanitized:
* Alphabetically sorted (A to Z)
* Stripped of structural dividers and list markdown (`-`, `=`)
* Retains necessary grammatical hyphens and parentheses for internal language names
